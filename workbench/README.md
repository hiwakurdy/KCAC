# Annotation Workbench

Open `home.html` in any modern browser (Chrome, Firefox, Edge).

Use the file-open buttons inside the editor to load:
- A page image (`.jpg`) from `ds_test/409/images/` or your images folder
- Its annotation JSON from `ds_test/409/annotationa/` or `output/consensus/`

No server is required — all processing happens in the browser.
