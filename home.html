Folder Workflow

  1. Click 📁 Image Folder → pick the folder with all your .jpg/.png files.
  2. Click 📁 JSON Folder → pick the folder with Surya or KCAC .json output.
  3. Files auto-pair by name (page_009.jpg ↔ page_009.json).
  4. Click any image in the left list. Edit boxes, page metadata, verification status, and transcriptions. Click next image → previous edits auto-save.
  5. The JSON folder needs read-write permission (browser will prompt).

KCAC Exports

Save keeps a KCAC JSON record with legacy text_lines and layout arrays. Export creates PAGE XML, ALTO XML, TEI P5, METS/MODS, IIIF 3.0, HuggingFace JSONL, Dataset Card, and Datasheet files.

Browser Support

Folder auto-save needs the File System Access API — works in Chrome, Edge, Brave, Opera. In Firefox/Safari you can still load files but saves will download instead.
